# Город на паузе — прототип для Т2

Статический интерактивный прототип приложения, основанный на предоставленных скриншотах. Не официальный сервис Т2.

## Сценарий презентации

Откройте `index.html`: «Больше» → карточка «Город на паузе» или пункт в «Сервисах» → карта Оренбурга → категория/поиск → точка или карточка → «Оценить загруженность» → сохранение. Пять вкладок внизу сохранены; остальные разделы — упрощённые демоэкраны. На компьютере показывается рамка телефона, на телефоне — полноэкранный интерфейс; предусмотрена компоновка для iPad.

Все места, координаты и показатели условные. Время ожидания не является прогнозом. Пользовательская оценка меняет только локальную демонстрацию. Оценки хранятся в localStorage (`t2-city-reports-v2`), не отправляются на сервер и удаляются кнопкой внизу «Больше». При запрете хранения отображается ошибка. Браузер может удалить данные при очистке сайта или завершении приватного сеанса.

Карта работает с локальной схематичной подложкой (не для навигации), масштабированием, перемещением и кликабельными точками. Через переключатель слоёв можно включить OpenStreetMap; это требует интернета и обращается к серверам OSM. Библиотека Leaflet 1.9.4 включена локально, лицензия — `assets/vendor/LEAFLET-LICENSE`.

## Локальный запуск

Сборка и установка зависимостей не нужны:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Для проверок браузера используется `tests/smoke.cjs` (нужен Playwright). Команда: `node tests/smoke.cjs`; сервер должен работать на порту 8000.

## GitHub Pages

1. Закоммитьте файлы и отправьте их в ветку `main` репозитория `nastyoren2005-ui/gorod-na-pauze`.
2. В GitHub откройте **Settings → Pages**.
3. В **Build and deployment → Source** выберите **Deploy from a branch**.
4. Выберите **main**, папку **/(root)** и нажмите **Save**.
5. После успешного развёртывания сайт будет доступен по адресу https://nastyoren2005-ui.github.io/gorod-na-pauze/ .

`index.html` находится в корне; пути относительные, сайт совместим с подпапкой GitHub Pages. `.nojekyll` отключает обработку Jekyll. Публикация не включена автоматически.
